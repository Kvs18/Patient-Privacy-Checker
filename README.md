# Patient Privacy Checker

An interactive educational checklist promoting patient data privacy and healthcare cybersecurity awareness.

## Features
- Interactive patient privacy checklist
- Real-time progress tracking
- Completion feedback and checklist reset
- Light and dark mode with saved preferences
- Responsive design

## Getting Started
1. Download or clone the repository.
2. Open `index.html` in your browser.
3. Complete the privacy checklist and track your progress.
